# Terminus

> Terminus is an account-based marketing (ABM) platform covering account-based advertising, web personalization, email-signature marketing (Sigstr), conversational chat (Ramble) and revenue measurement (BrightFunnel). Terminus merged into DemandScience on 2024-11-12; terminus.com now redirects to demandscience.com and the product runs as the DemandScience ABM Platform. Terminus-branded infrastructure remains in production. Two of the three APIs are behind a credential wall; the third — the Verify API — is publicly documented in prose and cURL, but ships no machine-readable specification.

Generated by API Evangelist from probed public surfaces on 2026-08-12. Method: generated (the provider publishes no llms.txt — https://demandscience.com/llms.txt returns 404, https://developer.terminus.com/llms.txt 302s to a login, and https://api.lastbounce.com/llms.txt returns 403).

## APIs

- [Terminus ABM Platform API](https://developer.terminus.com/): Base URL https://api.terminusplatform.com/. Live, but every anonymous request returns HTTP 401 "Authentication Invalid". Access is requested through a DemandScience support ticket.
- [Employee Automation API](https://support.demandscience.com/hc/en-us/articles/360051822454-Employee-Automation-API-for-Email-Experiences): Creates, updates and removes users and employee signature data in an Email Experiences (Signature Ads) account in real time. Current version v4 (July 2022). Host https://email.terminusplatform.com/. Access by support ticket; no public reference.
- [Verify API](https://support.demandscience.com/hc/en-us/sections/38485678357267-API-Documentation): Email verification, formerly Lastbounce, sold as Intelligent Verification. Base URL https://api.lastbounce.com/. THE ONLY PUBLICLY DOCUMENTED API of this provider — endpoints, auth header, error envelope and result-code vocabulary are all in the help center. Metered in prepaid credits (one credit per verification).

## Verify API operations

Auth: account key in the `x-api-key` request header. Anonymous calls are rejected at the AWS API Gateway edge with HTTP 403.

- `POST /api/singleEmail/validate?email={email}` — verify one address synchronously. Returns email, result, resultDetail, corrected, verifiedEmail, domain, localPart.
- `POST /api/batch/validation` — upload a CSV (multipart form field `file`, one column header containing "Email", or bare addresses one per line). Returns fileId and meta.batchJobId plus pre-processing counts.
- `POST /api/batch/{jobId}/status` — poll job progress. status is IN_PROGRESS or COMPLETED; carries countDetail, totalEmail, totalProcessedEmail, processed (percent), processedTime.
- `GET /api/file/download/{jobId}` — download the results CSV (Email, Verified Email, Corrected, Result, Additional Status Info).
- `generateUploadUrl` — required for files larger than 10MB; the path is not published, the article says the full documentation is supplied on request.

Async pattern: submit, then poll every 5–10 seconds for files under 1,000 records (less often for larger files), then download. There are no webhooks or callbacks.

Result vocabulary: VALID, INVALID, UNKNOWN, RISKY, DUPLICATE, ACCEPT_ALL, ACCEPT_ALL/KNOWN_USER, ACCEPT_ALL/UNKNOWN_USER. Result detail: OK, ANY_EMAIL_ACCEPTED, B2C, BAD, COMMON_TYPO, DISPOSABLE, DNS_FAILURE, DOMAIN_SUSPENDED, DUPLICATE, EXCLUDE, GREYLISTING, INVALID_CONVERSATION, INVALID_FORMAT, KNOWN_ACCEPT_ALL, KNOWN_NOT_ACCEPT_ALL, MAILBOX_FULL, ROLE_ACCOUNT, SERVER_CONFIG_ERROR, SPAM_TRAP, TIMES_OUT, UNABLE_TO_CONNECT, UNKNOWN.

Environments: https://api.lastbounce.com/ (production, default), https://sqa-api.lastbounce.com/ (SQA), https://dev-api.lastbounce.com/ (development). The same account key is used in all three; there is no free or simulated call path.

Errors: vendor JSON envelope with httpStatus, code, timeStamp, codeName, exceptionName, message. NOT RFC 9457. The API Gateway edge returns a different shape, `{"message":"..."}`, so a client must handle both.

## Limits and pricing

- No request-rate limit is published for any API, and no X-RateLimit-*, RateLimit-* or Retry-After header is returned. Consumption is metered in credits, not requests.
- Batch uploads: standard multipart upload up to 10MB; larger files must use generateUploadUrl. No hard file-size limit; 1,000,000 records (~20MB) is the recommended maximum.
- Audience Builder exports are capped at 100,000 companies and 100,000 contacts per export.
- No plans, tiers or price points are published. https://demandscience.com/pricing/ 301-redirects to a 710-byte PNG. Pricing is quoted after a sales conversation.

## Lifecycle

- [Chat Experiences Deprecation](https://support.demandscience.com/hc/en-us/articles/46047614705811-Chat-Experiences-Deprecation-December-31-2025): Chat Experiences and all its API endpoints were removed on 2025-12-31; chat data deleted by 2026-01-14.
- Verify uploaded files are retained 90 days. Credits are valid for the lifetime of the account.
- Status page: https://status.terminus.com/ redirects to terminus.statuspage.io/inactive — the Statuspage account is inactive and no replacement was found.
