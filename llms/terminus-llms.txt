# Terminus

> Terminus is an account-based marketing (ABM) platform covering account-based advertising, web personalization, email-signature marketing (Sigstr), conversational chat (Ramble) and revenue measurement (BrightFunnel). Terminus merged into DemandScience on 2024-11-12; terminus.com now redirects to demandscience.com and the product runs as the DemandScience ABM Platform. Terminus-branded infrastructure remains in production, but every API surface is behind a credential wall.

Generated by API Evangelist from probed public surfaces on 2026-08-05. Method: generated (the provider publishes no llms.txt — https://demandscience.com/llms.txt returns 404 and https://developer.terminus.com/llms.txt 302s to a login).

## APIs

- [Terminus ABM Platform API](https://developer.terminus.com/): Base URL https://api.terminusplatform.com/. Live, but every anonymous request returns HTTP 401 "Authentication Invalid". Access is requested through a DemandScience support ticket.
- [Employee Automation API](https://support.demandscience.com/hc/en-us/articles/360051822454-Employee-Automation-API-for-Email-Experiences): Creates, updates and removes users and employee signature data in an Email Experiences (Signature Ads) account in real time. Current version v4 (July 2022). Host https://email.terminusplatform.com/. Access by support ticket; no public reference.

## Specs
